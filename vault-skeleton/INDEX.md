# Index

The entry point to this vault.

- [[Dashboard]] — current status, regenerated by the agent
- [[_STRUCTURE]] — where things go and how to name them
- [[AGENTS]] — rules for the coding agent
- [[collab]] — what you are asking the class for, and what you can offer

## Areas

- `daily/` — daily capture notes
- `notes/` — durable notes, kebab-case
- `people/` — one file per person, `Firstname Lastname.md`
- `projects/` — one file per project, with `status:` and `description:`
- `references/` — source material and transcripts
- `learning/digests/` — nightly learning digests (generated)
- `report/` — the nightly report that this cell sends to the class manager (generated)
- `shared/` — the class notebook, a separate shared repository
