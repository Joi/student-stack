# Collaboration

Two lists. The nightly report reads the bullet lines under each heading and sends
them to the class manager, who pairs asks with offers across the cohort. Keep each
line short and specific — one ask or one offer per line, starting with `- `.

This file is student-authored. Write it yourself (the agent can help). Only the
bullet text under the two headings below is read; edit freely around it.

## Asks

What you are stuck on or want help with. Example: `- stuck on webhook signatures`.

## Offers

What you have figured out and could help someone else with. Example:
`- got LINE reply tokens working`.
